# Credit-Risk-Prediction
Credit risk assessment is one of the most critical applications of data science in the financial sector. When a bank or financial institution receives a loan application, they must decide whether to approve it based on the likelihood of the applicant repaying the debt. Manually reviewing every application is time-consuming.
This project uses Machine Learning to predict loan eligibility based on applicant profiles. It covers the full data science pipeline: from data cleaning and exploratory analysis to model training and evaluation.

## 🚀 Project Overview

The goal is to automate the loan eligibility process based on customer details provided during the online application form. These details include Gender, Marital Status, Education, Number of Dependents, Income, Loan Amount, Credit History, and others.

## 🛠️ Tech Stack & Dependencies

* **Python 3.x**
* **Pandas & NumPy**: For data manipulation and handling missing values.
* **Matplotlib & Seaborn**: For feature visualization.
* **Scikit-Learn**: For model training (Logistic Regression/Decision Tree) and evaluation.
